# Support

## Support Channels

### 📖 Documentation
Start with the [kffi documentation](https://graphiks-org.github.io/kffi/).

### 🐞 GitHub Issues
Use GitHub Issues for:
- Bug reports
- Feature requests
- Technical questions

https://github.com/Graphiks-org/kffi/issues

### 💬 GitHub Discussions
Use GitHub Discussions for:
- General questions
- Ideas and suggestions
- Community feedback

https://github.com/Graphiks-org/kffi/discussions

## Before Opening an Issue

1. Check existing documentation
2. Search for similar existing issues
3. Use the correct template (bug vs feature)
4. Provide as much context as possible
